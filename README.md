# Swarm Symphony

Swarm Symphony is an original browser/PWA music-breeding game inspired by the broad creature-collection and layered-orchestra genre. It uses original insect characters, original island concepts, original synthesized audio, and original vector artwork.

## Features
- 6 islands with distinct visual themes, scales, tempo, and arrangements.
- 36 insect performers and 4 collectible forms each, for 144 Field Guide entries.
- Visible sound-making animation: wings rub, shells clack, abdomens pulse, forelegs chime, proboscises play reed tones, and more.
- Breeding Hollow, Nursery, timers, offline progress, feeding to Level 20, castle upgrades, bed capacity, quests, dailies, individual mixer controls and muting.
- Four currencies: Coins, Nectar, Prisms, and Stormglass.
- Developer Console can add or set an exact amount of every currency and reset all data.
- Autosave, export/import, installable PWA, offline cache, touch-first responsive layout, desktop support.
- Music, SFX, and master volume sliders support 0 to 2000 percent.

## GitHub Pages
Upload every file from the ZIP directly into the repository root. Do not upload the ZIP itself as the website. In GitHub, open Settings, Pages, choose Deploy from a branch, select `main`, and choose `/ (root)`.

## Controls
All gameplay uses direct buttons and touch/click interactions. Tap a placed performer for feed, collect, mute, box, and per-performer volume controls.

## Audio and rights
No audio, visual assets, names, or character designs from My Singing Monsters are included. The soundtrack is generated at runtime with Web Audio oscillators/noise and original patterns.
